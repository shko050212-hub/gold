# GOLDSAFE (골드세이프) — 실시간 타임딜 특판 오픈런 & 맞춤 목돈 설계 플랫폼

**GOLDSAFE**는 한정 기간 동안 오픈되는 고금리 특판 상품에 선착순으로 가입하고, 금융감독원 오픈API로 수집한 전 금융권 예·적금 금리를 비교하여 개인의 보유 자산과 목표 기간에 맞는 최적의 계좌 포트폴리오를 설계해 주는 실시간 금융 플랫폼입니다.

---

## 1. 서비스 소개

### 대상 사용자
- **사회초년생 및 단기 목돈 마련 희망자:** 소액이라도 일반 예·적금보다 높은 금리의 초단기 특판 상품을 빠르게 선점하고자 하는 사용자
- **금리 비교 및 자산 배분 고민자:** 1금융권과 저축은행의 수많은 예·적금 상품을 일일이 비교하기 어렵고, 현재 보유 자금과 목표 금액·기간에 맞춘 세후 실수령액 계산이 필요한 사용자

### 해결하려는 문제
1. **선착순 특판 오픈런 트래픽 폭주 시 데이터 정합성 붕괴 문제:** 한정 수량 금융 상품에 다수의 요청이 동시에 몰릴 때 발생하는 초과 가입(오버부킹) 및 계좌 잔액 불일치 문제를 해결합니다.
2. **파편화된 금융상품 정보 탐색 비용 문제:** 제1금융권과 저축은행의 예·적금 금리를 한곳에서 조건별로 필터링하여 비교할 수 있도록 통합합니다.
3. **단순 금리 표기의 한계 해결:** 세전 연이율만 보여주는 기존 서비스와 달리, 현재 보유 자금·목표 금액·과세 유형·남은 기간을 종합해 실제 가입해야 할 계좌 조합과 세후 만기 실수령액을 산출합니다.

### 핵심 기능 (3 Core Features)
1. **선착순 타임딜 특판 가입 및 실시간 동시성 제어 (`POST /api/subscribe`)**
   - 정해진 오픈 시각(`open_at`) 카운트다운 및 잔여 좌석(`remaining_count`) 실시간 동기화
   - PostgreSQL 행 잠금(`SELECT ... FOR UPDATE`) 트랜잭션 적용으로 동시 요청 시에도 초과 가입 방지 및 원장 무결성 보장
2. **전 금융권 예·적금 금리 통합 비교 (`GET /api/bank-rates`)**
   - 금융감독원 금융상품통합비교공시(Finlife) 오픈API를 통해 1금융권·저축은행의 정기예금·정기적금 4종 데이터를 주기적으로 자동 수집(`node-cron`)
   - 상품 유형(`정기예금`/`정기적금`), 금융권(`1금융권`/`저축은행`), 가입 기간(`6`/`12`/`24개월`) 다중 필터링 및 최고우대금리순 정렬 지원
3. **맞춤 목돈 마련 & 추천 계좌 믹스 시뮬레이터**
   - 현재 보유 금액(DB 계좌 잔액 자동 연동), 목표 금액, 과세 유형(`일반과세 15.4%` / `세금우대 9.5%` / `비과세 0%`), 남은 기간(개월) 입력
   - 1순위 초단기 특판 → 2순위 보유 목돈 거치용 정기예금 → 3순위 부족 자금 적립용 정기적금 순으로 최적 계좌 리스트와 세후 만기 실수령액 자동 산출
